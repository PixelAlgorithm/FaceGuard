Rules:
- Download weights into `models/` (gitignored) with a script `scripts/fetch_models.sh`; pin URLs and record SHA-256.
- MiniFASNet: reproduce upstream crop scales exactly (V2 2.7×, V1SE 4.0×, 80×80, BGR). Before trusting outputs, verify which softmax index is "real" with a live webcam frame and a printed photo; record the finding in `edge/README.md`.
- Every signal function is pure: input frames/metadata → typed Pydantic signal object with score + reason code candidates. No decisions here — the policy engine decides.
- Run liveness and matching concurrently; the cloud `/v1/match` call is parallel and time-boxed (`latency_budget_ms.rekognition_timeout`; timeout → the attempt is OFFLINE, P7). No per-attempt cloud schedule call. Warm all models at startup; log per-stage latency_ms.
- Depth arrives by push from the DepthProbe app (`GET /v1/depth/pending`, `POST /v1/depth/frames`); wait at most `latency_budget_ms.depth_max_wait` after the RGB frames, else depth is `NOT_AVAILABLE`.
- Retired endpoint names (do not implement): `/v1/authenticate`, top-level `/v1/challenge`, `/v1/stepup`, `/v1/fallback/verify`, `/v1/enrol`, `/v1/attempts/{id}`, `/status`, `/admin/connectivity`. The eval path uses `POST /v1/admin/eval/context` + `GET /v1/events` (no `X-Eval-Label` header); the edge never exports embeddings.
- Thresholds only from `config/thresholds.yaml`. Any exception in a stage → the policy runtime's DENY `SYSTEM_ERROR`, never HTTP 500.
- **Test on your own port, never against the live `:8000` edge** (the operator's demo instance; kiosk on `:5173`). Start a scratch instance, e.g. `EDGE_DATA_DIR=/tmp/edge_<you> uvicorn edge.app:app --port 81xx`, and never reset, reconfigure, re-sign the bundle of, or load-test the live one.
- Use `fastapi-patterns` and `python-patterns` skills.
- Done = `pytest edge` passes, `ruff check` clean, and a measured latency table (p50/p95 over ≥20 runs, on your own port) in `eval/results/latency_edge.md`. Report commands and outputs.
